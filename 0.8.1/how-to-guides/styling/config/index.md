# Config

This section showcases how to use the [datachart.config](https://eriknovak.github.io/datachart/0.8.1/references/config/index.md) module to customize the global style of the `datachart` package.

Let's start by importing the necessary functions to help us work with the `datachart.config` module.

```
from datachart.config import config
```

The `config` instance is a global configuration that the users can interact with. It allows them to customize the global style of the `datachart` package.

Furthemore, the instance is of the [datachart.config.Config](https://eriknovak.github.io/datachart/0.8.1/references/config/#datachart.config.Config) class.
