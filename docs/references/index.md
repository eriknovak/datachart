## Where to Look

| I want to…                                                   | Page |
| :----------------------------------------------------------- | :--- |
| draw a chart and see what each parameter accepts             | [charts](charts/index.md), one page per chart: the function, its data record, its `style` keys, and its constants |
| know the settings any chart takes, or the keys a theme holds | [typings](typings.md): reference lines and bands, texts, legend, emphasis rule, colorbar, and the theme style |
| find the values a parameter accepts                          | [constants](constants.md), with a table of constants by chart |
| change the look of every chart                               | [config](config.md) to apply and adjust a theme, [themes](themes.md) for the predefined looks |
| overlay charts, arrange them in a grid, annotate, or save    | [utils](utils/index.md): `Panel`, `Grid`, `Annotate`, and `save_figure` |
| compute the number a chart shows                             | [utils.stats](utils/stats.md): centers, spreads, correlations, fits, intervals, smoothers, densities |

The [how-to guides](../how-to-guides/index.md) show the same API on real data, feature by feature.
