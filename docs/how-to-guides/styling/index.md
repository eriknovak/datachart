# Styling

The styling guides cover everything that controls how charts look: the predefined themes and how to apply, build, and share your own through the [config](../../references/config.md) singleton, and the available colormaps. Each card names a guide, says what it covers, and links to it.

-   [Theme Gallery](theme-gallery.ipynb)

    Every predefined theme as a card of color swatches with hex codes and six signature charts, grouped by use, to pick one by eye.

-   [Colormaps](colormaps.ipynb)

    Every `COLORS` palette by kind, with the predefined themes that use it, and which kind fits which theme attribute.
